Logson

Observability for AI agents — records every run and span, replays the execution tree.

Problem

When an AI agent finishes a task, the reasoning behind it is gone — a wall of console output, or nothing at all. Debugging a multi-agent pipeline means guessing which tool fired, in what order, and which one quietly returned nothing.

Solution

Logson instruments any AIOS with a drop-in Python SDK that records runs and spans over HTTP. A FastAPI backend stores the telemetry in Postgres and a React viewer replays each run as an execution tree — every tool call, its inputs, its outputs and its failures. The SDK no-ops when the collector URL is unset, so an instrumented agent never crashes because Logson is down.

Tech Stack

FastAPI PostgreSQL React 19 TypeScript Python SDK Observability

Key Features

Every Run, Every Agent

One table of every recorded run across every AIOS, with status, type, start time and duration

Filter by AIOS

One click narrows thousands of runs down to a single agent's history

Execution Tree per Run

Each run opens as a span waterfall, indented by sub-agent, so nested calls read at a glance

Inspect Any Tool Call

Click a span to see the exact input and output JSON the agent sent and received
