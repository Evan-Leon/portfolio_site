Co-Author

A story planning studio that turns scattered ideas into a timeline and a script.

Problem

Writers collect characters, places and scenes across notebooks and files, then lose the thread of how any of it fits together. The structural work — what happens in what order, who is in which scene, how long the whole thing actually runs — gets deferred until it is a rewrite.

Solution

Every story element gets a quick-add and a guided detail page, then the views that show how the pieces connect derive themselves: a timeline assembled from the events you already wrote, and a storyboard that groups beats into acts against a runtime target. A research agent proposes characters, places, events and a chronology — nothing is created until you approve it.

Tech Stack

Django 5 DRF PostgreSQL React 19 TypeScript PWA

Key Features

Story Dashboard

Every element type, its count and its latest entries on one screen

Guided Character Pages

Quick-add a name, then develop it through prompted craft sections

Self-Assembling Timeline

Events order themselves, carrying their linked characters and settings

Storyboard Runtime Budget

Beats grouped into acts and totalled live against the story's target
