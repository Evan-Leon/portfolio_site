Leon's Budget

Upload bank PDFs, categorize transactions, and track spending trends automatically.

View on GitHub

Demo coming soon

Problem

Manually tracking finances across multiple bank accounts is tedious and error-prone, making it hard to understand spending patterns.

Solution

Upload PDF bank statements directly — the app parses transactions automatically, categorizes them intelligently, and visualizes your spending trends over time.

Tech Stack

Django DRF React TypeScript PDF Parsing Chart.js

Key Features

PDF Upload & Parsing

Drag and drop bank statement PDFs for automatic transaction extraction

Smart Categorization

Transactions automatically tagged by merchant and spending category

Trend Visualization

Interactive charts showing spending patterns by category and over time

Multi-Account

Track multiple bank accounts in a single unified dashboard
