co-host

A production desk that walks a podcast episode from premise to teleprompter.

Problem

Writing a podcast is not one task. It is a premise, a beat sheet, a draft, a read-through and a recording, and every stage has its own craft rules. Point an AI chat at the whole thing and it collapses into a single prompt and hands back a script that sounds like nobody — and that you have to rewrite before you can read it aloud.

Solution

co-host gives each show a versioned bible — segment contract, runtime window, words per minute — and holds every episode to it through seven gated stages. Generation runs as a pipeline job at each gate, but the gates belong to the operator: nothing advances until the story and ear passes are signed off, and every stage can step back. The last stage is a teleprompter that reads the marked-up script back with per-segment timing.

Tech Stack

FastAPI React 19 TypeScript PostgreSQL Agentic AI

Key Features

Channels with Versioned Bibles

Each show carries a segment contract, runtime window and words per minute — every word budget downstream derives from it

Seven Gated Stages

Idea, beat sheet, draft, table read, ready to record, recorded, handed off — each with an explicit gate and a step-back

Script Studio

Marked-up script with per-segment time budgets and version history, beside the story and ear passes that gate the stage

Performance Mode

A record-trim teleprompter with segment and episode timers, per-segment energy notes and stumble flags
