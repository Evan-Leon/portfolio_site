AI-Built Built with Claude Code

chudios

A post-production pipeline where AI does the work and every stage stops for your yes.

Problem

Handing a recording to an AI pipeline is easy; trusting what comes back is not. Transcription, QC, clip selection and marketing copy all arrive as artifacts someone has to read, compare against the script, and decide about — and without a place to do that, the work either ships unreviewed or never ships at all.

Solution

chudios is the desk where those decisions happen. Each stage — once-over, clipper, marketing, ready-to-release — is a gated pipeline job that produces a reviewable artifact and then stops, so a recording only advances when a human approves it. The AI itself runs elsewhere; chudios owns when stages run and what the results mean.

Tech Stack

FastAPI React 19 PostgreSQL TypeScript Human-in-the-loop

Key Features

The Once-Over Gate

QC verdict, runtime against target, and a word-level script-vs-transcript diff on one approval screen

Findings You Can Act On

Every flub, dropped beat and consistency note is a card you can promote straight into a clip candidate

Ranked Clip Sheet

Candidates ordered best-first with editable in/out points, hooks and captions, behind a keep-gate

Ready To Release

Recording, transcript, clips and marketing kit in one place with a per-destination published checklist
