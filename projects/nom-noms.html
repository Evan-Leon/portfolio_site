Nom Nom's

Recipe scraper with LLM-assisted parsing, cook mode, and shop mode.

View on GitHub

Demo coming soon

Problem

Saving recipes from the web means navigating ads, life stories, and inconsistent formatting — making cooking from a saved recipe frustrating.

Solution

Paste a recipe URL and the app scrapes and parses it with LLM assistance into a clean, structured format. Cook mode guides you step-by-step; shop mode generates your grocery list.

Tech Stack

FastAPI React TypeScript LLM Web Scraping

Key Features

URL Recipe Scraping

Paste any recipe URL for instant, clean extraction

LLM-Assisted Parsing

AI normalizes inconsistent recipe formats into structured data

Cook Mode

Step-by-step cooking guidance with ingredient tracking

Shop Mode

Auto-generated grocery lists from any recipe or meal plan
