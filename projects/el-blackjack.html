El Blackjack

Mobile blackjack trainer for learning optimal strategy.

View on GitHub

Demo coming soon

Problem

Learning blackjack basic strategy requires memorizing complex decision tables that are hard to study without a realistic practice environment.

Solution

A mobile-native blackjack trainer that gives real-time feedback on your decisions compared to optimal basic strategy — so you learn by doing.

Tech Stack

React Native TypeScript

Key Features

Strategy Training

Play full blackjack hands against a dealer using optimal rules

Real-time Feedback

Instant feedback when you deviate from basic strategy

Basic Strategy Chart

Built-in reference chart for any hand situation

Session Stats

Track your accuracy and improvement over multiple sessions
