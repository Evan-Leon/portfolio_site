AI-Built Built with Claude Code

CHUD

A local-LLM agent that runs a self-built app portfolio: briefings, approvals, telemetry.

Problem

Two dozen self-built apps generate more context than one person can hold — which repo moved, which service is degraded, what deserves the next four hours. That context is scattered across git history, docs, dashboards and half-remembered decisions, and re-deriving it every morning is the biggest standing tax on shipping anything.

Solution

CHUD is a Pydantic AI agent on FastAPI that indexes the whole portfolio through a RAG service and answers from it using a local model on llama-swap — no cloud inference, nothing leaving the box. It opens each day with a generated briefing, routes every change it wants to make into a human approval inbox instead of acting unattended, and runs its scheduled work on a Temporal worker.

Tech Stack

Python 3.13 FastAPI Pydantic AI React 19 PostgreSQL RAG

Key Features

EVOsystem Daily

A generated morning briefing: suggested focus, a per-project plan, and every open flag across the portfolio

Grounded Codebase Chat

Ask about any repo; the agent calls its own tools and RAG index, and shows every tool call it made

Human-in-the-Loop Reviews

Flags, dev tasks and wiki drafts queue for an explicit approve or reject — nothing lands unattended

Live Hardware Telemetry

CPU, memory, GPU, disk and network for the machine the local models run on, with 24-hour trends
