The Classic

Golf tournament management and scoring app.

View on GitHub

Problem

Running a casual golf tournament means manually tracking scores on paper, calculating handicaps, and updating everyone on standings in real time.

Solution

A tournament management app where organizers set up events and players enter scores from their phones — with live leaderboards and automatic handicap calculations.

Tech Stack

Django React TypeScript

Key Features

Tournament Management

Create and configure tournaments with custom formats and rules

Live Scoring

Players enter scores from mobile devices with instant leaderboard updates

Leaderboard

Real-time standings with handicap adjustments and tiebreaker rules

Player Profiles

Track player history, handicap index, and tournament results
