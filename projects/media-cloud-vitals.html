Media Cloud Vitals

Performance monitoring dashboard for the Media Cloud platform.

View on GitHub

Problem

The Media Cloud platform had no internal visibility into system health, API performance, or usage patterns — making it hard to catch issues before users did.

Solution

An internal performance dashboard pulling metrics from across the platform stack — with real-time health checks, API response time tracking, and usage analytics for the ops team.

Tech Stack

Django React D3.js

Key Features

Performance Metrics

Real-time tracking of API response times and throughput

System Health Monitoring

Uptime checks and service health indicators across the platform

Usage Analytics

Track active users, query volumes, and popular features over time

Alerting

Threshold-based alerts for degraded performance or error rate spikes
