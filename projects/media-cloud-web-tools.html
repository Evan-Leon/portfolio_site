Media Cloud Web Tools

Media analysis platform for researchers and journalists.

View on GitHub

Problem

Researchers studying media coverage had no accessible tool for searching and analyzing millions of news articles across sources and time periods.

Solution

A full-featured web platform for searching, filtering, and visualizing news coverage — with tools for topic mapping, source comparison, and trend analysis built for academic researchers.

Tech Stack

Django React Redux D3.js PostgreSQL

Key Features

Media Search & Analysis

Search millions of articles across hundreds of news sources

Data Visualization

Interactive D3.js charts for coverage trends and source breakdowns

Research Tools

Export data, build word clouds, and compare sources side-by-side

Topic Mapping

Identify and visualize how topics spread across the media landscape
