ShowRunner Digest

Data visualization platform for television industry insights.

View on GitHub

Problem

Television industry data is spread across disparate sources, making it hard for producers and analysts to spot trends in viewership, demographics, and content performance.

Solution

An interactive data visualization dashboard that aggregates TV industry data into filterable D3.js charts — making trend analysis accessible without raw data wrangling.

Tech Stack

JavaScript D3.js HTML CSS

Key Features

Interactive Charts

D3.js-powered visualizations with hover tooltips and click-through details

Data Filtering

Filter by network, genre, time period, and demographic segment

Trend Analysis

Identify viewership patterns and content performance trajectories

Responsive Design

Fully responsive dashboard that works on desktop and tablet
