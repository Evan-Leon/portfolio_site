## Rules added & rules-index candidates
**Added:** `SDS-011` (theater rules-index, at Evan's direction, 20:29) — *a rule that hides the theater states a property of the theater, never a judgement about it, and is re-checked against that property whenever the property changes.* Cited at its point of use beside the surviving `prefers-reduced-motion` hide.

**Candidates (shared-tier; carried up verbatim):**
- **Fake-clock APIs that also fake timers can hang a page's own startup path** — prefer `setFixedTime` when the reveal depends on timers. `promote → tooling` — swept: EVO-TOOL-221
- **A module that exists to be stubbed in a falsification must not duplicate the logic it delegates.** `promote → universal` — swept: EVO-UNI-212
- **A composited layer's cost is its rastered AREA, not its largest dimension — so splitting it changes nothing;** lay it out smaller and `scale()` it back. `promote → universal` — swept: EVO-UNI-210
- **`backface-visibility: hidden` on a plane laid flat by `rotateX(-90deg)` deletes it** — any "free" win of that size is a rendering bug until a screenshot says otherwise. `promote → react-frontend` — swept: not promoted — CSS-3D-plane-specific; no fleet repo does CSS 3D transform planes today
- **A `toContain` on one member of a composite computed value passes for every arrangement of the others** — pin the whole value as a literal or parse each part with its position. Sibling of `EVO-UNI-018`. `promote → universal` — swept: EVO-UNI-214
- **A fixed overlay with one control in it needs `pointer-events: none` on the container and `auto` on the control, and nothing but a click test will tell you it does not.** `promote → react-frontend` — swept: EVO-FE-284
- **A hit-test assertion must not pick its point from `getBoundingClientRect` when the element is 3D-transformed** — ask `elementsFromPoint` instead. `promote → react-frontend` — swept: EVO-FE-285
- **Telling a human to "set" a read-only DOM property produces a confident false negative, not an error** (`window.devicePixelRatio = 2` fails silently) — confirm the mechanism can change it and have them read it back. `promote → universal` — swept: EVO-UNI-213
- **A `pgrep`/`grep` whose pattern appears in the checking command's own command line matches itself** — match the resolved binary path, a captured PID, or a sentinel file. Same family as `EVO-UNI-061`. `promote → tooling` — swept: not promoted — covered by EVO-TOOL-220 + EVO-TOOL-200
- **A phase's own `<verification>` grep can be unsatisfiable under the repo's formatter** — use a whitespace-insensitive equivalent, never reformat the file to satisfy the check. `promote → tooling` — swept: EVO-TOOL-222
- **A phase gated on a measurement states the not-yet-measured case as an explicit stop, alongside the failure verdicts** — else an executing session infers a verdict from downstream artefacts. `promote → universal` — swept: EVO-UNI-215
- **When a decision row records a ruling rather than a measurement, the measurement cells say `not taken` and a footnote names what was never run.** `promote → universal` — swept: EVO-UNI-216
- **A source comment must not contain the string a verification grep is asserting the absence of** — reword the comment, don't loosen the grep. `promote → tooling` — swept: EVO-TOOL-222
- **A geometric precondition measured at one viewport is not evidence for another, and a test that loops over viewports must state per-viewport whether the precondition holds** — a per-case `overlaps` literal, never a bare early return. promote → tooling — swept: EVO-TOOL-223
- **When a browser test asserts a per-element property over a collection, assert each element against the value its own attributes say it should carry** — a collection count plus a first-element spot check is the same vacuous check twice. promote → tooling — swept: not promoted — covered by EVO-UNI-018 + EVO-UNI-181
- **A phase gated on a decision row must state its own stop condition; a gate that lives only in the next phase does not hold.** promote → universal — swept: EVO-UNI-215
- **A click-through suite that runs at one viewport proves nothing about the others, and the gap can hide a total interaction failure rather than a degradation.** promote → tooling — swept: EVO-TOOL-223
- **Text that must fit a fixed box is verified by measuring `scrollWidth`/`scrollHeight` against the clip box, never by looking at a screenshot** (raised as `SDS-011` draft in the marquee session — note the ID collides with the theater-hide `SDS-011` actually added later the same day; the shared-tier candidate is the measurement rule). promote → universal — swept: EVO-UNI-217
