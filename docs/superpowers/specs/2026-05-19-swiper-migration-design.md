# Swiper.js Migration Design

**Date:** 2026-05-19
**Status:** Approved

## Problem

The custom `slideshow.js` implementation is buggy and unreliable. It requires manually writing out dot buttons for each slide, has click-propagation issues when slideshows are nested inside `<a>` link wrappers, and lacks touch/swipe support.

## Solution

Replace the custom slideshow with Swiper.js (v11) loaded via CDN. No build toolchain required — the site remains static HTML.

---

## CDN Includes

Add to every HTML file (10 total: `index.html` + 9 project pages). Remove the old `slideshow.js` script tag from each file at the same time.

**`index.html`:**
```html
<!-- In <head> -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.css">

<!-- Before </body> — replace old slideshow.js script tag -->
<script src="https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.js"></script>
<script src="assets/js/swiper-init.js"></script>
```

**Project pages (`projects/*.html`):**
```html
<!-- In <head> -->

```

## HTML Markup Migration

**Before (custom):**
```html
<div class="slideshow">
  <div class="slideshow__track">
    <img class="slideshow__slide" src="..." alt="...">
  </div>
  <button class="slideshow__arrow slideshow__arrow--prev">&#8249;</button>
  <button class="slideshow__arrow slideshow__arrow--next">&#8250;</button>
  <div class="slideshow__dots">
    <button class="slideshow__dot slideshow__dot--active"></button>
  </div>
</div>
```

**After (Swiper — project detail pages):**
```html
<div class="swiper project-swiper">
  <div class="swiper-wrapper">
    <div class="swiper-slide"><img src="../images/project-name/01.png" alt="Project — screenshot 1" loading="eager"></div>
    <div class="swiper-slide"><img src="../images/project-name/02.png" alt="Project — screenshot 2" loading="lazy"></div>
    <div class="swiper-slide"><img src="../images/project-name/03.png" alt="Project — screenshot 3" loading="lazy"></div>
    <div class="swiper-slide"><img src="../images/project-name/04.png" alt="Project — screenshot 4" loading="lazy"></div>
    <div class="swiper-slide"><img src="../images/project-name/05.png" alt="Project — screenshot 5" loading="lazy"></div>
  </div>
  <div class="swiper-button-prev"></div>
  <div class="swiper-button-next"></div>
  <div class="swiper-pagination"></div>
</div>
```

Each project detail page gets exactly 5 slide slots pre-filled with the `01.png`–`05.png` naming convention. Drop screenshots at those paths and they appear automatically. Pagination dots are auto-generated by Swiper.

**Missing image handling:** `swiper-init.js` removes any `.swiper-slide` whose image 404s before initializing Swiper, so pages with fewer than 5 screenshots will never show blank or broken slides. Swiper sees only the slides that actually loaded. For example, `budget-app` currently has 4 images — its 5th slot will be silently pruned at runtime. Note: `pruneMissingSlides` uses `new Image()` load/error events, which require HTTP to work correctly — it will not reliably detect missing files on `file://` origins during local testing.

**After (Swiper — index page project cards):**
```html
<div class="swiper card-swiper">
  <div class="swiper-wrapper">
    <div class="swiper-slide"><img src="images/project-name/01.png" alt="..." loading="eager"></div>
    <div class="swiper-slide"><img src="images/project-name/02.png" alt="..." loading="lazy"></div>
    ...
  </div>
</div>
```

No nav buttons, no pagination — just the wrapper. Swiper handles autoplay and swipe.

Cards with only 1 image skip Swiper initialization entirely (no looping artifacts).

Card images are the same files already used on project detail pages — they are always present on disk, so `pruneMissingSlides` is not needed for card swipers.

## JavaScript

Delete `assets/js/slideshow.js`.

Create `assets/js/swiper-init.js`:

```js
(function () {
  'use strict';

  // Remove swiper-slides whose images 404, then run callback with remaining count.
  function pruneMissingSlides(el, callback) {
    const slides = Array.from(el.querySelectorAll('.swiper-slide'));
    let pending = slides.length;
    if (!pending) { callback(0); return; }

    slides.forEach(function (slide) {
      const img = slide.querySelector('img');
      if (!img) { if (--pending === 0) callback(el.querySelectorAll('.swiper-slide').length); return; }
      const test = new Image();
      test.onload = function () {
        if (--pending === 0) callback(el.querySelectorAll('.swiper-slide').length);
      };
      test.onerror = function () {
        slide.remove();
        if (--pending === 0) callback(el.querySelectorAll('.swiper-slide').length);
      };
      test.src = img.src;
    });
  }

  document.addEventListener('DOMContentLoaded', function () {

    // Project detail pages — full nav, after pruning missing slides
    document.querySelectorAll('.project-swiper').forEach(function (el) {
      pruneMissingSlides(el, function (count) {
        if (count === 0) return;
        new Swiper(el, {
          loop: false,
          navigation: {
            nextEl: el.querySelector('.swiper-button-next'),
            prevEl: el.querySelector('.swiper-button-prev'),
          },
          pagination: {
            el: el.querySelector('.swiper-pagination'),
            clickable: true,
          },
          keyboard: { enabled: true },
        });
      });
    });

    // Index page cards — autoplay only, no nav.
    // Cards with 1 image skip init entirely (no looping artifacts).
    // preventClicks/preventClicksPropagation: false ensures link clicks work
    // when the swiper is nested inside an <a> wrapper.
    document.querySelectorAll('.card-swiper').forEach(function (el) {
      const slides = el.querySelectorAll('.swiper-slide');
      if (slides.length <= 1) return;
      new Swiper(el, {
        loop: true,
        autoplay: { delay: 2500, disableOnInteraction: false },
        allowTouchMove: true,
        preventClicks: false,
        preventClicksPropagation: false,
      });
    });

  });
})();
```

## CSS

Remove all `.slideshow*` rules from `assets/css/styles.css` (lines 1052–1160, including the section comment).

`.project-card__image` already has a fixed height defined earlier in `styles.css` — the `height: 100%` rules on `.swiper` and `.swiper-slide` rely on this and require no change.

Add Swiper theme overrides in place of the removed rules:

```css
/* === SWIPER === */

/* Theme — match site purple accent */
.swiper-button-next,
.swiper-button-prev {
  color: var(--purple-accent, #7c3aed);
}

.swiper-pagination-bullet-active {
  background: var(--purple-accent, #7c3aed);
}

/* Project detail slideshow sizing */
.project-detail__demo .swiper {
  width: 100%;
}

.project-detail__demo .swiper-slide img {
  width: 100%;
  height: auto;
  display: block;
}

/* Card slideshow — fill fixed-height container */
.project-card__image .swiper,
.project-card__image .swiper-slide {
  height: 100%;
}

.project-card__image .swiper-slide img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```
