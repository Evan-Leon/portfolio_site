## Days
- 2026-08-25 — drive-in theater: full roadmap + DTF falsifier + nine phases shipped (12 sessions).

## Accomplished
The week's single active day took the drive-in theater from idea to a
nearly-complete build. A twelve-phase roadmap (brainstorm → spec → Parts 1–3,
two cold Sonnet evaluators + a Codex review that added a DT10 production-cutover
gate). DTF falsified the core assumption in real Chrome (`GO`, 4.5× margin) and
established the load-bearing finding that **decode count, not the CSS 3D
transform, dominates cost**. Phases DT0–DT7 shipped the theater end to end:
pnpm workspace + vendored engine, multi-stage Docker build serving `/theater/`,
page shell, the lit-poster lot, per-screen video activation, accessibility
(keyboard drive-by-focus + reduced motion + narrow layout), a six-spec Playwright
suite, and the homepage hero CTA. DT8/DT9 piloted the automated showcase flow on
chunk-norris and produced the reusable `portfolio-showcase` meta-prompt.

Three real defects were caught by tests/tools rather than by eye and fixed: a
`fromTo` `immediateRender` seek bug (DT3), a first-approach clip-activation gap
(DT4, fixed in DT5), and a `perspective`/`translateZ` wrapper that silently
swallowed every pointer event over screen 0 since DT3 (DT6).

## Rules added & rules-index candidates
Repo has a rules-index opt-out, but nine candidates were surfaced for the shared
EVOsystem stacks and carried verbatim from the 2026-08-25 daily (still unswept —
promote tags intact):

- (universal) A falsifier's baseline is not automatically its cheapest variant —
  state what it holds constant and check the ordering before reading a difference
  as a cost. `promote → universal` — swept: EVO-UNI-204
- (universal) A verdict recorded with different instrumentation than a
  pre-registered protocol must state the deviation and the absorbing margin in
  the same place the verdict is read. `promote → universal` — swept: EVO-UNI-205
- (universal) Write a decision row in the exact form the phase's own verification
  command greps for (`**GO**` did not match the `(GO|GO-REDUCED|NO-GO)` regex).
  `promote → universal` — swept: EVO-UNI-206
- A GSAP `fromTo` renders its `from` at build time (`immediateRender` true by
  default); set `immediateRender: false` on every `fromTo` not starting at
  position 0, or a mid-timeline seek diverges from a scrub-back (SDS-001). (No
  promote tag in source.) — swept: kept local — GSAP-specific; no fleet repo uses GSAP today
- (universal) An adapter's `observe` must read state the animation library
  actually *wrote* (inline transform / custom property), not only the adapter's
  own computed numbers. promote → universal — swept: kept local — tied to this repo's adapter/observe (SDS) architecture; principle already near EVO-UNI-136
- (universal) A test fake standing in for a DOM constructor must produce a real
  `Node` when anything downstream reasons about the DOM (leaked-listener check +
  `{ once: true }` handlers). promote → universal — swept: EVO-FE-281
- (react-frontend) An adapter that holds state across its own `load()` must
  re-apply it when `load()` finishes — the first `seek` lands before a
  dynamically-imported renderer exists and the epsilon guard suppresses the
  re-delivery. promote → react-frontend — swept: kept local — specific to this engine's construct/seek/load lifecycle; no other fleet repo has this adapter pattern today
- (react-frontend) Placement a breakpoint must override belongs in custom
  properties with `!important`; an inline declaration outranks every stylesheet
  rule, so moving from inline `transform` to inline custom props buys nothing
  alone. promote → react-frontend — swept: EVO-FE-282
- (tooling) A CSS `perspective` ancestor makes every 3D-transformed wrapper a
  hit-testing plane that silently swallows its children's pointer events; give
  the moving wrapper `pointer-events: none` and descendants `auto`.
  `promote → tooling` — swept: EVO-FE-283
- (universal) An e2e spec importing the same module the page is built from cannot
  fail on a change to it — pin one assertion to a witness the module does not
  generate. Specialises `EVO-UNI-061`. `promote → universal` — swept: EVO-UNI-207
- (tooling) A falsification `sed` that changes a TS signature or an event name
  breaks the build, not the test — write breakages that stay type-valid and check
  the failure message names the intended assertion. `promote → tooling` — swept: EVO-UNI-208
